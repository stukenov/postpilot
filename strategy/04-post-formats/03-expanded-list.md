# Expanded List

## What is this
A longer post with a bulleted or numbered list where each item includes a short explanation.

## Why it's in the strategy
For when a list alone is useful but loses depth and practical value without context behind each point.

## When to use
- When each item needs a brief explanation, example, or clarification.
- When you want to combine the scannability of a list with expert-level breakdown.

## How to build this type of post
1. Open by naming the problem or goal the list addresses.
2. Break the content into distinct items.
3. After each item, add one to two sentences of context or a concrete example.
4. Make sure the list reads as a coherent whole, not a set of disconnected notes.

## Possible applications
- Common mistakes in client onboarding, each with a note on what goes wrong and why.
- A set of tools or approaches with a short comment on when each fits best.

## What to keep in mind
- Each explanation should add something the item alone doesn't say.
- If the explanations start running long, consider splitting into a thread instead.
