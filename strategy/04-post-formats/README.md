# Post Formats

This section covers the core formats for packaging content. These are not funnel stages — they are structural choices that determine how a single idea gets delivered based on its scope, depth, and how the audience will consume it.

## Section focus
- Goal: Match the format to the idea, not the other way around.
- Role in strategy: A technical layer. The same insight can be packaged in multiple ways depending on what it needs to do.

## How to use this section
- Choose the idea and the goal first, then pick the format.
- Short formats work best for a single sharp point. Long formats work best for deep breakdowns.
- Don't lock any content type to a single format — any strategic angle can be delivered in any form.
