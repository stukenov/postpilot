# Note

## What is this
A post with an attached note — a longer text artifact linked from the main post body.

## Why it's in the strategy
Useful when the main idea should stay short but additional detail, structure, or reference material is worth preserving separately.

## When to use
- When the core message needs to be brief but supporting detail is genuinely useful.
- When you want to give the reader a handy attached reference — a checklist, a breakdown, a how-to.

## How to build this type of post
1. Write the post as a short entry point with a clear promise of value.
2. Put the structure, list, or detail inside the attached note.
3. Make sure the post works on its own — the note is an add-on, not a crutch.
4. Use the note to extend, not to compensate for an underdeveloped idea.

## Possible applications
- A short post on getting started in a new area, with an attached note containing a full step-by-step checklist.
- A single sharp observation with an attached note laying out the underlying framework or practice.

## What to keep in mind
- The post must hook without the note. Most readers won't open it.
- Don't use the note to hide raw or unfinished thinking — it should be as clean as the post itself.
